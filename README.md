# Introdução ao JavaScript — Aula 5

Exercícios introdutórios de JavaScript com exemplos de variáveis, operações aritméticas, conversão de tipos, listas, condicionais e loops.

## Requisitos

- Node.js instalado

## Como executar

Abra a pasta no VS Code ou em um terminal e rode um dos arquivos com Node.js. Por exemplo:

```bash
node 1-meuPrimeiroPrograma.js
```

Outros exercícios disponíveis:

- `2-trabalhandoComVariaveis.js`
- `3-operacoesAritmeticas.js`
- `4-conversaoDetipos.js`
- `5-atribuicaoVariaveis.js`
- `6-listas.js`
- `7-condicionais.js`
- `8-loops.js`

Para executar outro exercício, substitua o nome do arquivo no comando `node`.
